# Sunae

Astro + SolidJS + Tailwind CSS v4 によるミニマルなスターターサイト。

## コマンド

| コマンド       | 説明                              |
| :------------- | :-------------------------------- |
| `pnpm install` | 依存関係のインストール            |
| `pnpm dev`     | 開発サーバー起動 (localhost:4321) |
| `pnpm build`   | 本番ビルド (`./dist/`)            |
| `pnpm preview` | ビルド結果のプレビュー            |

## デプロイ

`main` ブランチへのプッシュで GitHub Pages へ自動デプロイされる。
