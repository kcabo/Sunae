# Sunae (砂絵)

オフラインで動作する自分だけのメモ帳を作れるサービスです。
ブラウザ上で[ブックマークレット](https://ja.wikipedia.org/wiki/%E3%83%96%E3%83%83%E3%82%AF%E3%83%9E%E3%83%BC%E3%82%AF%E3%83%AC%E3%83%83%E3%83%88)として動作します。

世界一シンプルで、世界一起動が速い (はずです多分)

https://kcabo.github.io/Sunae/

---

## 使い方

1. [サイト](https://kcabo.github.io/Sunae/) を開きます
2. 好みのカラープリセット（32種類）やレイアウトを選びます
3. 「ドラッグ＆ドロップ」ボタンをブックマークバーへドラッグします
4. 以降はそのブックマークをクリックするだけでメモ帳が開きます

## 仕組み

Sunae は `data:text/html,...` 形式の URL をブックマークとして保存することで動作します。クリックするとブラウザが直接 HTML を描画し、`contenteditable` な `<body>` にそのまま入力できます。サーバーもデータベースも存在しません。

カスタマイズした設定はブックマーク URL 自体に埋め込まれます。設定を変更した場合は、新しいブックマークとして登録し直してください。

なお、保存・共有・履歴の復元はできません。ページを閉じると内容は消えます。砂絵のように儚く。

## 開発

| コマンド       | 説明                              |
| :------------- | :-------------------------------- |
| `pnpm install` | 依存関係のインストール            |
| `pnpm dev`     | 開発サーバー起動 (localhost:4321) |
| `pnpm build`   | 本番ビルド (`./dist/`)            |
| `pnpm preview` | ビルド結果のプレビュー            |

**技術スタック**: Astro + SolidJS + Tailwind CSS v4

## デプロイ

`main` ブランチへのプッシュで GitHub Pages へ自動デプロイされます。
